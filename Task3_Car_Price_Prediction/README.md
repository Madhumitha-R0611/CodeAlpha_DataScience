# Task 3 - Car Price Prediction

This project predicts used car selling prices using machine learning.

### Technologies
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

### Algorithm
Random Forest Regression

### Features
- Year
- Present Price
- Driven Kilometers
- Fuel Type
- Selling Type
- Transmission
- Owner

### Result
The model predicts car prices based on the given vehicle features.
